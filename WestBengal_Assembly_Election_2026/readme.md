## 🚀 Key Features
* **Real-time GIS Mapping:** Interactive visualization of constituency-wise leads using Leaflet.
* **Live Analytics:** Tracks seat shares, winning margins, and party performance.
* **Demographic Deep-Dive:** Detailed breakdowns of voter turnout, gender ratios, and elector counts.
* **Granular Filtering:** Toggle between District and Constituency levels for localized insights.

---

## 📊 Data Sources
This dashboard processes data from official electoral portals:
* **Primary Results:** [Election Commission of India (ECA)](https://results.eci.gov.in/ResultAcGenMay2026/index.htm)
* **Elector Statistics:** [CEO West Bengal - Constituency-wise Elector Data](https://ceowestbengal.wb.gov.in/Election_current/4428)
